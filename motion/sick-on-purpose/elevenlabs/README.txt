HOW TO RECORD
1. Open each DOC_xx file in order -> Ctrl+A, Ctrl+C -> paste into ElevenLabs with Doc's voice -> generate.
   Download each as the same name with .mp3  (e.g. DOC_01_cold-open.mp3)
2. Open CELL_all_lines.txt -> paste with Cell's voice -> generate once -> save as CELL_all_lines.mp3
3. Put all the .mp3 files in this folder. I'll match every line to its spot automatically.
Blank lines between sentences = natural pauses.
